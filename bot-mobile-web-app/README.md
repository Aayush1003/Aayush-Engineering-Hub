# Engineering Hub Bot — mobile web app

A responsive, dependency-free chatbot interface for the Aayush Engineering Hub. Open `index.html` in a browser to try the starter demo.

The chat UI currently uses simple example responses for interview preparation, DSA, and system design. It does not send messages to an AI service. Connect a backend/API before using it as a live bot; keep any API secrets on the server, not in browser JavaScript.
