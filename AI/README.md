# AI Learning Hub

A beginner-friendly, engineering-focused path through artificial intelligence: where it began, how modern machine learning works, and how to build and evaluate AI systems responsibly.

## Start here

1. [AI history: 1956 to today](history/AI-HISTORY.md) — a guided timeline, beginning with the Dartmouth workshop.
2. [Foundations and learning path](fundamentals/README.md) — concepts to learn in sequence, with practice ideas.
3. [Transformers and “Attention Is All You Need”](transformers/README.md) — a plain-language guide to the 2017 paper that introduced the Transformer architecture.
4. [AI engineering](engineering/README.md) — a practical project layout, testing, reproducibility, evaluation, and deployment checklist.
5. [Resources](resources/README.md) — papers, books, courses, and documentation.

## Suggested learning sequence

- Begin with the history and basic Python, linear algebra, probability, and statistics.
- Learn supervised learning, evaluation, and neural-network fundamentals before deep-diving into Transformers.
- Read the Transformer guide alongside the original paper; implement a tiny attention example before trying a full model.
- Build a small, measurable project and document its data, evaluation, limitations, and setup.

This folder is intentionally separate from the DSA and system-design tracker so AI materials can grow into their own learning and project area.
