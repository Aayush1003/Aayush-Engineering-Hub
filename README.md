# Aayush Engineering Hub

A beginner-friendly engineering learning hub for AI, interview preparation, data structures, and system design. Start with the [AI Learning Hub](AI/README.md) for a guided learning path, or use [Interview Ready](Interview-Ready/README.md) for interview practice.

## Explore this repository

- **[AI Learning Hub](AI/README.md):** AI history, fundamentals, Transformers, engineering practices, and resources.
- **[AI agents and workflows](AI/agents/README.md):** a plain-language guide to how agents work, how to read their code, and which of Aayush's AI repositories to study.
- **[Interview Ready](Interview-Ready/README.md):** DSA and system-design tracker plus a technical interview question bank.
- **[DSA and System Design Sheet](Aayush-DSA-System-Design-Sheet.csv):** practice tracker.

## Suggested starting point

If you are new to AI, read [AI foundations](AI/fundamentals/README.md), then [AI agents and workflows](AI/agents/README.md). When exploring an implementation, trace its entry point, input validation, model call, tool execution, state, stop condition, and tests. A project README may describe goals beyond what the current code implements, so compare documentation with source and tests.
