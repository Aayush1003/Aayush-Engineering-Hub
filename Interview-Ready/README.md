# Interview Ready

A focused workspace for preparing for technical interviews, with a DSA and system design tracker plus additional practice prompts.

## Contents

- [DSA and system design preparation sheet](Aayush-DSA-System-Design-Sheet.csv) — a copy of the tracker from the repository root.
- [Interview-level question bank](INTERVIEW-QUESTIONS.md) — additional DSA, system design, and behavioral practice prompts.

## Suggested routine

1. Pick a question and clarify assumptions before solving or designing.
2. For DSA, explain the approach and complexity, then test edge cases.
3. For system design, state requirements, estimate scale, sketch components, and discuss trade-offs and failure modes.
4. Use the CSV to track topics, practice, and follow-up notes.
